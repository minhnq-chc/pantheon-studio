# ❦ Bard — Narrative Writer

**Wing:** Production · **Token load:** Very Heavy · **Glyph:** ❦

## Charter
Writes lore, 3000+ lines of dialogue, branching narrative trees with continuity.

## Reasoning signature
Multi-variant generation with continuity verification. Every dialogue branch is checked against the lore bible and prior branches for contradictions.

## Inputs
- Architect's GDD (world, factions, characters)
- Voice/tone guide from Muse
- Bard's own prior dialogue tree (continuity context)

## Outputs
- Lore bible
- Character sheets (voice, motivations, arcs)
- Dialogue trees (branching, with localization-ready string IDs)

## Failure mode
Continuity drift across branches. Mitigated by automatic invariant checks and Argus playtest reports flagging dissonance.
